# GMC Redux Todo List

A Todo List application built with React and Redux Toolkit. It allows users to manage their tasks through a simple interface, with global state management using Redux.

## Features

- **Add tasks:** Create tasks with a name and description.
- **Edit tasks:** Update the name and description of existing tasks.
- **Mark as completed:** Toggle tasks between completed and active.
- **Delete tasks:** Remove tasks from the list.
- **Filter tasks:** View all tasks, active tasks, or completed tasks.
- **Task counters:** See the total number of tasks in each filter.
- **Responsive design:** Use the application on desktop and mobile screens.
